# WooCommerce Technical SEO Checklist

Adapted from the Shopify version of this framework for a WooCommerce / WordPress store (t-shirt / apparel, Printful fulfillment).

## SEO Plugin Setup

| Item | Detail |
|------|--------|
| Plugin | Rank Math (recommended) or Yoast SEO |
| Focus keyword | Set per product — matches the primary keyword used in the LLM prompt |
| Title template | `%title% %sep% %sitename%` — keep primary keyword first in the product title itself |
| Meta description | Pull directly from the LLM-generated `meta_description` field (≤165 chars) |
| Canonical URL | Auto-generated by plugin — verify no duplicate canonicals on variable products (size/color variations) |
| Sitemap | Confirm product post type + product_cat taxonomy are included in XML sitemap |

## Permalinks / URL Structure

| Item | Detail |
|------|--------|
| Setting | Settings → Permalinks → Custom: `/product/%postname%/` (or `/shirts/%postname%/` if you want a category prefix) |
| Slug source | Use the `url_handle` field generated by the LLM prompt, not the raw title |
| Consistency | Keep slug pattern identical across all products — don't mix `/product/` and `/shop/` |

## Product Content Fields (WooCommerce → WP mapping)

| WooCommerce field | Source from LLM output |
|---|---|
| `post_title` | Product title |
| `post_content` | Full description (long) |
| `post_excerpt` | Short description (shown near Add to Cart — keep to 1-2 punchy sentences, not a repeat of the long description) |
| `_yoast_wpseo_title` / `rank_math_title` | Meta title |
| `_yoast_wpseo_metadesc` / `rank_math_description` | Meta description |
| `post_name` (slug) | URL handle |
| Product image `_wp_attachment_image_alt` | Alt text (one per image, no duplicates across variations) |

## Variable Products (Size / Color)

- Each variation should **not** get a separate meta title/description — SEO metadata lives on the parent product only.
- Alt text can differ per variation image (e.g., "Black cotton t-shirt front view" vs "Black cotton t-shirt back view with print detail").
- Avoid thin/duplicate content: don't spin up separate posts per color — use WooCommerce attributes + variations, not separate products, unless each genuinely targets a distinct keyword (e.g., "oversized graphic tee" vs "fitted graphic tee").

## Images

- Compress before upload (WebP where possible) — apparel product pages are image-heavy and page speed is a ranking factor.
- Filename and alt text come from the LLM prompt output — apply before upload, not after (WooCommerce doesn't bulk-rename on import).
- Set a consistent image naming convention across the whole catalog, e.g. `[product-slug]_[view].jpg` (`vintage-graphic-tee_front.jpg`).

## Schema / Structured Data

- Rank Math and Yoast auto-generate `Product` schema, but verify these fields populate correctly for a t-shirt catalog:
  - `price` and `priceCurrency` (check variable-product price range shows correctly)
  - `availability` (in stock / out of stock synced with Printful inventory)
  - `aggregateRating` / `review` (only if you have real reviews — don't fake it)
  - `size` / `color` as `additionalProperty` if your theme/plugin supports it — helps for "size chart" type queries
- Test with Google's Rich Results Test after generating a batch of products.

## Category / Collection Pages

- Each product category (e.g., "Graphic Tees", "Oversized Fits") needs its own SEO title + meta description — use the Category Description Prompt from `prompt-templates.md`, not the product prompt.
- Category archive template should render the category description above or below the product grid (not hidden) — it needs to be crawlable, not just present in the DB.

## Common WooCommerce-Specific Pitfalls

1. **Duplicate content from variations** — WooCommerce sometimes indexes `?attribute_size=...` URLs; set canonical to the base product URL.
2. **Thin category pages** — an empty or near-empty category description hurts; always fill it even for small collections.
3. **Slow product pages** — apparel stores lean on many high-res images; lazy-load and compress, or Core Web Vitals will drag rankings regardless of content quality.
4. **Print-on-demand sync gaps** — if Printful sync overwrites `post_content` or `post_excerpt` on re-sync, your SEO copy can silently get wiped. Verify field mapping in your sync settings, or apply SEO content in a step *after* sync, not before.
5. **Missing breadcrumbs schema** — WooCommerce themes vary; confirm breadcrumb markup is present, it's a small but real GEO/AEO citability signal too.
